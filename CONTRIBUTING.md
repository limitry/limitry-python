# Contributing

Thank you for taking the time.

This repository holds the source of the Limitry Python SDK. It is
**generated**: each release writes it from Limitry's own
repository, so a change made here directly would be overwritten by the
next release.

- **Issues** are welcome: bugs, questions and ideas.
- **Pull requests** are read, every one. A good change is ported into
  Limitry's repository with you credited as a co-author, it
  ships in the next release, and the pull request is closed with a link to
  that release.

By opening a pull request you agree that your contribution is licensed
under the Apache License 2.0, as this repository is (section 5 of the
licence).
